# 2026年10月 集客改善と月末判定

更新日: 2026-10-03。時刻は日本時間。

## 目的と判定

目標は、札幌・小樽・千歳・北広島を中心に、恵庭も含めた民泊清掃・リネン需要から、実際の商談と契約を増やすこと。検索順位やCTRは中間指標とし、契約と採算を優先する。検索最上位や脱広告は約束できないため、10月末の実測で広告の継続・縮小・停止を決める。

## 10月の変更

- 5つの地域LPで、冒頭の文章を清掃・リネン・報告など依頼者の便益から説明し、地域固有の対応範囲を示す。
- 概算・詳細見積もり予約とは別に、4項目で送れる初回相談フォームを設置。正式料金は現地調査後に確定と明記。
- 初回相談フォームの送信成功時のみ広告コンバージョンを発火。メールに初回流入元、UTM、GoogleクリックID、送信ページを付与する。
- 既存の概算・予約フローは残し、正式な見積もりを希望する利用者に使ってもらう。
- 料金・人員・実績の表記は BUSINESS.md を基準とし、トップの清掃員数を約80名に修正。
- 会社側の説明から始まる抽象的な見出しを、担当者・写真報告・清掃手順が分かる説明に修正。根拠のない「最短1週間」「初期費用0円・固定費0円」を削除。
- 問い合わせ送信とTimeRexの日時予約完了を画面上で区別し、予約完了時だけ完了案内と概要書リンクを表示するよう修正。
- GA4用のイベント計測コードを準備。測定IDが未設定の間は送信しない。設定後はページ閲覧、概算、フォーム開始、送信成功、予約完了を区別する。
- 地域別5広告が審査承認となり、旧混在グループを停止。日額予算1,000円は据え置き。

## 週次で見るもの

1. Google広告: 費用、クリック、検索語、地域別広告グループ、端末、コンバージョン、検索語に対する無関係な流入。
2. Search Console: サイト全体と地域ページ別の表示回数・クリック・CTR・平均掲載順位。指名検索と非指名検索を分ける。
3. 受信した実問い合わせ: 広告・自然検索・不明の区別、重複、商談化、契約、見込み売上。メールの attribution フィールドとGoogle Ads計測を照合する。
4. 初回相談フォームと正式見積もりフォームの件数を分け、商談化率を見る。流入から離脱までの正確なファネルにはGA4のウェブ測定IDとイベント実装が必要。

## 10月末の判断

10月1日〜31日と9月1日〜30日を比較する。広告は費用÷有効リード、費用÷商談、費用÷契約、契約粗利との比較で評価する。自然検索は非指名検索のクリック数、地域ページのクリック数、有効リード・商談・契約を評価する。順位だけが上がっても商談が増えなければ成功としない。広告由来の商談・契約が乏しいまま費用が先行する場合は、広告を縮小または停止し、自然検索・LP改善に予算を寄せる。Nestex様の結果は成約時点で再評価する。

GA4とSearch ConsoleのSupermetrics接続は2026-10-02に完了。Search Consoleの対象は `https://windwoods-stayble.com/`。接続されているGA4にはWindWoodsと確認できるウェブプロパティが見つかっていないため、GA4上の直帰率・スクロール・フォーム到達率はまだ実測できない。広告CTRが高いことだけでLP離脱を断定しない。
