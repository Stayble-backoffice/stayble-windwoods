# 2026年10月 集客改善と月末判定

更新日: 2026-10-03。時刻は日本時間。

## 目的と判定

目標は、札幌・小樽・千歳・北広島を中心に、恵庭も含めた民泊清掃・リネン需要から、実際の商談と契約を増やすこと。検索順位やCTRは中間指標とし、契約と採算を優先する。検索最上位や脱広告は約束できないため、10月末の実測で広告の継続・縮小・停止を決める。

## 10月の変更

- 5つの地域LPで、冒頭の文章を清掃・リネン・報告など依頼者の便益から説明し、地域固有の対応範囲を示す。
- 概算・詳細見積もり予約とは別に、4項目で送れる初回相談フォームを設置。正式料金は現地調査後に確定と明記。
- 初回相談フォームの送信成功時のみ広告コンバージョンを発火。メールに初回流入元、UTM、GoogleクリックID、送信ページを付与する。
- 既存の概算・予約フローは残し、正式な見積もりを希望する利用者に使ってもらう。
- 料金・人員・実績の表記は BUSINESS.md を基準とし、トップの清掃員数を約80名に修正。
- 会社側の説明から始まる抽象的な見出しを、担当者・写真報告・清掃手順が分かる説明に修正。根拠のない「最短1週間」「初期費用0円・固定費0円」を削除。
- 問い合わせ送信とTimeRexの日時予約完了を画面上で区別し、予約完了時だけ完了案内と概要書リンクを表示するよう修正。
- GA4プロパティとウェブデータストリームを新設し、測定ID `G-90WPJ6DVVF` を公開済み。ページ閲覧、概算、フォーム開始、送信成功、予約完了を区別する。`generate_lead` と `booking_complete` をキーイベントに登録した。公開後のトップページ閲覧はGA4リアルタイム画面で受信を確認した。実際の問い合わせ・予約によるCV受信は未発生。
- 地域別5広告が審査承認となり、旧混在グループを停止。日額予算1,000円は据え置き。

## 週次で見るもの

1. Google広告: 費用、クリック、検索語、地域別広告グループ、端末、コンバージョン、検索語に対する無関係な流入。
2. Search Console: サイト全体と地域ページ別の表示回数・クリック・CTR・平均掲載順位。指名検索と非指名検索を分ける。
3. 受信した実問い合わせ: 広告・自然検索・不明の区別、重複、商談化、契約、見込み売上。メールの attribution フィールドとGoogle Ads計測を照合する。
4. 初回相談フォームと正式見積もりフォームの件数を分け、商談化率を見る。流入から離脱までの正確なファネルにはGA4のウェブ測定IDとイベント実装が必要。

## 10月末の判断

10月1日〜31日と9月1日〜30日を比較する。広告は費用÷有効リード、費用÷商談、費用÷契約、契約粗利との比較で評価する。自然検索は非指名検索のクリック数、地域ページのクリック数、有効リード・商談・契約を評価する。順位だけが上がっても商談が増えなければ成功としない。広告由来の商談・契約が乏しいまま費用が先行する場合は、広告を縮小または停止し、自然検索・LP改善に予算を寄せる。Nestex様の結果は成約時点で再評価する。

Search ConsoleのSupermetrics接続は2026-10-02に完了。対象は `https://windwoods-stayble.com/`。GA4の新しいウェブプロパティは2026-10-03に作成され、ページ閲覧の受信を確認した。ただしSupermetricsのGA4接続一覧には同日まだ新プロパティが表示されず、同接続からのサイト別GA4集計は未取得。再表示を確認してからGA4の流入・離脱・フォーム到達を分析する。広告CTRが高いことだけでLP離脱を断定しない。

Google広告の10月1日〜3日の検索語レポートには、旧混在グループ由来の「リネン サプライ 札幌」1クリック・248円のみがクリック付きで表示された。地域別5グループの成果はまだ計測期間が短く、良否は判断しない。広告費は広告管理データ上の金額であり、請求書の税込額とは区別する。

競合の公開ページでは、[Hoan Clean](https://hoanclean-hokkaido.com/) がリネンサプライと運営上の悩みを、[おそうじハウス札幌](https://osojihouse.net/lp/minpaku-cleaning/) が料金条件と作業範囲を明示している。WindWoodsは自社の料金体系・提供範囲を正確に示し、地域ページから初回相談または概算に進める構成を継続して改善する。競合の価格・実績を自社の事実として流用しない。

## 10月3日の追加運用

- Google広告のキャンペーンと地域別5グループは有効、広告審査はすべて承認済み。キャンペーンは入札戦略の学習中で、日額予算は1,000円のまま。10月1日〜3日の広告グループ別レポートでは旧グループに44表示・5クリック・費用1,122円、新5グループはまだ表示・クリックが集計されていない。旧グループは停止済みで、この数値は停止前を含む。新グループの成績は判断しない。
- 関連する「宿泊施設 清掃」等まで遮り得るキャンペーンの部分一致除外語「宿泊」を削除した。他の除外語、地域設定、予算、入札戦略は維持した。変更結果は広告接続で `applied` と確認。
- Search Consoleの10月1日〜3日のページ別暫定集計は、トップ11表示・1クリック、千歳16表示・1クリック、小樽10表示・0クリック、札幌6表示・0クリック、北広島2表示・0クリック。期間が短く、データ反映にも遅れがあるため効果判定には使わない。
- 10月3日時点の受信箱には、10月のWeb3Forms問い合わせ通知はまだない。Nestex様は9月18日に初回MTG後の資料・仮見積もりを送付済みで、その後の成約通知は確認できない。Qualia様は自然検索由来の千歳案件で、メール上は10月5日12時の商談を合意済み。いずれも未契約として扱う。
- トップページから地域選択なしでも初回相談に進めるフォームを設置。送信成功時のみ既存の広告CV・GA4 `generate_lead` を発火し、エリアと初回流入情報を問い合わせに添付する。
- 料金の内訳を比較できる独立ガイドを公開し、トップと各エリアの料金セクションからリンク。1Rの清掃費と1回あたり請求額を区別し、BUSINESS.mdにある税込料金・供給方式のみ掲載した。
- 全6既存ページの構造化データの更新日を本文更新日の10月3日に合わせた。恵庭ページのtitleは、検討者の主目的である清掃・リネンを先に示す表現へ変更した。フッターの別事業への離脱リンクを削除した。

## 月末までの運用条件

10月の途中も広告の検索語・費用・有効問い合わせ、Search Consoleの地域別非指名クエリ、GA4のページ・フォームイベントを定期的に照合する。新広告グループは表示・クリックが蓄積する前に停止判断しない。Nestex様・Qualia様の商談・契約結果は、判明した時点で広告と自然検索を分けて採算へ反映する。10月末に初めて月間比較を確定する。
